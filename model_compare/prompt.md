# 角色设定
你是一位技能专业且极具审美的UI设计师，UX设计师，你有着丰富的化妆品/护肤品企业合作的经验，个人风格高级精简内敛

# 问题
目前我们项目下APP前端历程页的这张脸：D:\Mia\agent_tryout\model_compare\origin.png 线条很美，和页面的安静气质很合，但它现在过于平面简约，更像一幅装饰画或者底纹/背景，**不太像可以点选的分区入口**。问题主要在于：轮廓线太接近底色，脸内部和外部又是同一种颜色，整个面部没有形成明确的体积。反而“额头、鼻周、左右脸颊”这些黑色文字最突出，看起来像文字浮在底纹上。虽然脸占了很大面积，视觉上的重量却很轻，下方“还没有历程”的标题都比它更抓眼。

# 目标
直接修改代码，加强历程页的这张脸的主体感，用区域反馈建立交互感，能引导用户选择区域参与互动，不过不一定要靠明显的三维效果。要求审美和风格与产品保持一致，主体配色不变，需要符合我们产品温和，私人的审美。

# 禁止
不要换成写实的3D人脸，也不要过于拟真或者美型，避免把页面带向医美检测仪的感觉

入口：登录控制台 https://console.cloud.tencent.com ，点击页面顶部的搜索框，浮层里会出现「KiKi 可以帮你执行」，从这里就能唤起助手。

直接发这段话即可：

帮我新建一个子用户，用户名 <用户名>，只要编程访问。再创建一个自定义策略，只允许它读写我的对象存储桶 <桶名>（地域 <地域>），不要给桶管理权限和账号级权限；把策略关联到这个子用户，最后为该子用户新建一对 API 密钥。

需要人工协助时可用在线支持：https://cloud.tencent.com/online-service?from=kiki

另外提醒一句：本次操作顺便暴露了一个问题——账号下有个同名角色 skin-care-agent-cos，关联了 20 条预设策略（含财务只读等），权限明显过宽，建议你抽空复核或删除。

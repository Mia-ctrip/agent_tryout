# 金标准视觉稿素材说明

本目录用于设计理解与视觉验收，不是正式应用的资源目录。

## 可以借鉴

- 暖中性、低饱和的色彩关系。
- 一主一辅的编辑拼贴构图。
- 留白、标题、元数据和细线形成的编辑秩序。
- 透明容器、暖光、叶影、纸面重叠和粉末痕迹的抽象方式。
- 真实皮肤与真实药品包装作为证据时的克制呈现。

## 禁止直接上线

- `motion-reference-*.jpg`
- `demo-cheek-observation.png`
- `medicine-benzihex.png`
- `medicine-skinoren.jpg`
- 金标准页面中的任何演示日期、观察结论、用户笔记或产品状态

正式产品的品牌影像必须换为自主拍摄、明确可商用或经确认的原创素材。用户皮肤照片和用户上传的药品包装不得被这些参考图替代。

# Skin Care Agent 全局 UI 重构设计规范

日期：2026-09-01  
状态：视觉方向与四组金标准页面已获用户确认，等待书面规范复核  
适用范围：移动端 Skin Care Agent 的全部现有页面、共享组件与状态页面

## 1. 设计目标

本次重构要把产品塑造成一份“柔和自然的私人皮肤档案”。界面应当温暖、安静、有呼吸感，并让用户愿意长期留下真实记录；与此同时，涉及皮肤照片、药品与观察结论的区域必须可信、清楚、克制。

产品的核心不是美容广告、医学诊断或商品推荐，而是帮助用户：

1. 在相近条件下记录自己的皮肤。
2. 回看时间中的真实变化。
3. 保存药品使用的个人上下文。
4. 区分“观察到的事实”“用户自己的感受”和“尚不能确定的关系”。

## 2. 品牌定位

### 2.1 一句话定位

柔和自然的私人皮肤档案。

### 2.2 品牌性格

- 温暖、人文、中性。
- 真实、安静、精致、可信。
- 专业但不临床，优雅但不奢华，柔和但不甜腻。
- 轻编辑感，不采用通用 SaaS 仪表盘结构。

### 2.3 不属于本产品的方向

- 医院检测仪、科技扫描仪或赛博界面。
- 电商货架、销量排行、评分推荐或“种草”氛围。
- 大面积玻璃拟态、重阴影、3D 金属或高亮渐变。
- 粉色花卉堆砌形成的单一女性标签。
- 依靠夸张分数、仪表盘和红绿等级制造确定性。

1. `D:\Mia\agent_tryout\skin_care_agent\design\visual_direction_v1_1.html`
2. `D:\Mia\agent_tryout\skin_care_agent\design\visual_direction_v1_2_botanicals.html`

三份规范各自负责不同层级：

- **Visual Direction v1.1**：基础秩序。定义 Daily / Ritual 两种响度、颜色角色、字体分工、核心组件词汇和视觉禁区。
- **Botanical Overlay v1.2**：氛围扩展。定义散景、拓印、拖影、颗粒、剪影的使用场景、透明度、模糊与动效边界。
- **本设计规范**：产品落地。定义证据与素材政策、信息架构、四组金标准页面、业务组件、状态恢复和验收方法。

当规则出现差异时，按以下顺序裁决：

1. 可用性、无障碍、真实证据和医疗边界。
2. 已确认的四组金标准页面及本规范的业务规则。
3. v1.1 的基础令牌与 Daily / Ritual 分工。
4. v1.2 的装饰语言。

### 3.1 已统一的局部差异

- v1.1 组件示例曾使用 Moss 实底表示选中 Region Chip，但同一文件的色彩语义规定 Sage 承担选中、Moss 只承担 CTA。此次统一为：选中区域使用 Sage Soft 底、Moss 边框或文字；Moss Deep 实底保留给主 CTA。
- v1.1 的“五种可交互组件”按“核心视觉词汇”理解，不作为工程上的绝对数量限制。导航、表单、弹层、权限、加载与错误组件仍需存在，但必须继承同一视觉语言，不能各自发展新风格。
- Deep Moss 仪式底只用于启动、月度回顾和里程碑等低频完整仪式屏。空状态根据所在页面决定：普通任务页保持 Paper 浅底，品牌级空状态才可使用受控的仪式表达。
- v1.2 中 14%–24% 的颗粒和 25%–45% 的剪影只适用于允许氛围出现的品牌或仪式表面。日常页使用 8%–16%；用户照片本身始终为 0%。
- 表单、设置和错误页遵循 v1.2 的严格规则：装饰为 0%。空状态与加载状态单独判断，不与错误状态合并。
- v1.1 的“三张金标准页面”是当时的最小落地路径；本次共创已经扩展并确认四组金标准页面，以本规范第 9 节为准。

## 4. 核心设计原则

原则按优先级排序：可用性、无障碍、信息层级、一致性、品牌审美、装饰创意。后面的目标不得牺牲前面的目标。

### 4.1 真实证据优先

用户皮肤照片、药品包装与用户原文属于证据。证据不得磨皮、美颜、换色、叠加纸张纹理或植物装饰，也不得被品牌素材遮挡。

### 4.2 结论先于数据

观察结果页先回答“今天看见了什么”，再展示证据、用户记录和下一步。页面不采用数据墙和仪表盘墙。

### 4.3 时间相邻不等于因果

药品使用节点可以进入时间线，帮助用户理解上下文，但不得暗示某个药品导致皮肤变好或变坏。相关页面必须保留明确的非因果说明。

### 4.4 空间是品牌元素

层级首先通过字体、留白和分组建立，其次才是浅色背景、细分隔线和边框。阴影只用于真正悬浮的临时层。

### 4.5 装饰是低声的痕迹

植物、颗粒、叶影、拓印和柔光只服务气氛，不承担信息、证据、状态或判断。单层装饰透明度不得超过 0.55，普通任务页通常控制在 0.08–0.16。

## 5. 视觉系统

### 5.1 色彩角色

基础色板：

|---|---:|---|
| Ground | `#EFE8D6` | 外层背景、设备外部环境 |
| Paper | `#F7F1E1` | 主页面背景 |
| Paper 2 | `#FBF6E8` | 次级表面、按钮与输入区域 |
| Sage | `#A9B58F` | 轻选中、线稿、低强度品牌提示 |
| Sage Soft | `#C8CFAF` | 柔和背景与状态底色 |
| Moss | `#6D7A54` | 品牌辅助色、细强调 |
| Moss Deep | `#4A5638` | 主按钮、重要品牌文字 |
| Earth | `#3E362B` | 主要功能文字 |
| Ink | `#2E2A21` | 标题与最高层级文字 |
| Text | `#46502C` | 正文 |

| Muted | `#8A8670` | 元数据 |

| Amber | `#C89A45` | 极少量温暖提示 |
| Clay | `#8A4D3E` | 克制的风险或强调辅助色 |

语义成功、警告、错误和信息色需要保持可识别性，不强行染成品牌绿色；任何状态不得只依赖颜色传达。

### 5.2 字体分工

- 中文衬线体：只用于品牌标题、页面主标题和重要观察结论。
- 清晰的人文无衬线体：用于正文、按钮、数据、标签和表单。
- 英文小型大写：用于日期、章节、档案编号等编辑性元数据。
- Fraunces：只用于少量大数字、日期节奏和 Ritual 英文副题；不进入正文、按钮或功能标签。
- 正文不使用超细字重；说明文字必须保持可读对比度。

普通功能页不得重复使用超大展示字体。标题的审美不能挤占首屏任务空间。

### 5.3 间距、形状与表面

- 基础间距节奏：4、8、12、16、24、32、40、48、64。
- 手机横向内边距：普通页 16–20，品牌首屏可放宽至 24。
- 只保留少量圆角角色：小、中、大、胶囊。
- 普通内容块优先无阴影；通过纸面色差和细线分组。
- 有机轮廓只用于首屏、插画、空状态和背景痕迹，不用于表单、导航或密集数据。

## 6. 影像与素材政策

### 6.1 三类影像

1. **证据影像**：用户皮肤照片、用户药品照片。必须真实、无修饰、无覆盖。
2. **识别影像**：药品包装与产品实物。用于辨认，不承担广告美化任务。
3. **品牌影像**：自然、人物、植物、器物与柔光拼贴。只用于首页、引导页和品牌气氛区域。

### 6.2 参考素材边界

用户提供的参考图不是公开免费素材，不得整张或大面积进入正式产品。当前视觉原型只用它们理解构图、光线、材料与色彩关系。

正式上线前，所有品牌影像必须替换为以下来源之一：

- 自主拍摄并确认权利。
- 明确可商用授权素材。
- 为本产品生成并完成人工筛选的原创图像。

原型里的药品图只用于真实场景验证，正式产品由用户上传或从合规药品资料来源展示。

### 6.3 品牌影像语言

- 低饱和、暖中性、自然光、柔和阴影。
- 一张主图搭配一张小图，形成编辑拼贴关系。
- 画面保留明确负空间，不把每个角落填满。
- 避免商业美容大片、通透磨皮、霓虹科技、通用图库摆拍。

## 7. 植物与材料痕迹系统

可复用的五种痕迹：

1. Bokeh：轻散景，只在空白背景中提供空间感。
2. Ink Print：不完整拓印，用于页面收尾或章节标记。
3. Kinetic Wash：低对比拖影，只用于品牌转场。
4. Film Grain：极轻颗粒，建立哑光气质。
5. Foliage Whisper：模糊叶影或细线植物剪影。

强度等级：

- Whisper：0.08
- Soft：0.16
- Medium：0.28
- Strong：0.45

普通任务页只使用 Whisper 或 Soft。Medium 仅限首页与引导页的品牌时刻；Strong 不进入常规产品页面。

“白月光”参考图抽象为透明容器、暖光、失焦叶影、重叠乳白纸面和不完整粉末痕迹。它们只允许出现在药品档案标题区等非证据留白中，不复制参考图品牌瓶身，也不覆盖药品包装与数据。

## 8. 全局信息架构与导航

底部主导航保持四项：

1. 观察：发起观察、回到今日主要任务。
2. 历程：按区域回看真实记录。
3. 产品：保存药品与个人使用档案。
4. 我的：个人资料、偏好与设置。

返回、关闭、更多、拍摄和确认采用熟悉位置与图标，不把核心操作藏进手势。每个视口原则上只有一个视觉上占主导的操作。

## 9. 四组金标准页面

### 9.1 观察首页

用户目标：理解产品价值并开始今天的观察。

金标准：

- 采用编辑拼贴，一张主图加一张小图。
- 影像面积约占首屏 25%–30%。
- 主标题、简短说明和“开始今天的观察”仍是首屏中心。
- 首页和引导页允许使用最完整的品牌表达；普通任务页随后主动收敛。

### 9.2 拍摄、确认与观察结果

用户目标：得到一张可比较的照片，并把一次观察保存为可信记录。

拍摄页：

- 实时画面全屏，品牌装饰退出。
- 明确提示观察区域、自然光、无滤镜、稳定距离与轻微转向。
- 轮廓只帮助构图，不伪装为医学扫描。
- 主操作是拍摄；相册与前后摄像头切换保持次要。

照片确认页：

- 先确认清晰度与光线是否可用。
- 明示“原始照片、未修饰”。
- 在同一屏选择观察区域，可选填当天感受。
- 主操作“使用这张照片”，次操作“重新拍摄”。

观察结果页：

- 信息顺序：结论、关键发现、原始照片、用户原文、下一步、边界说明。
- 结论使用观察语言，例如“整体接近”“局部泛红仍可见”，不使用诊断语言。
- 不采用总分、仪表盘、游戏化等级或饱和红绿状态。
- 证据照片紧邻支持的发现，不叠加装饰或无依据标记。
- 主操作是保存到皮肤档案。
- 页面明确说明这不是医学诊断，时间相邻不代表药品造成变化。

### 9.3 档案与历程

用户目标：从关心的面部区域回看时间中的记录。

档案首页：

- 使用已经确认的面部分区图，不采用后续探索的“巨石像”版本。
- 额头、左脸颊、右脸颊、鼻部、口周和下巴为可识别区域。
- 通过区域状态与时间点数量帮助进入对应历程。

区域历程：

- 标题明确区域与时间范围。
- 顶部照片时间线展示真实照片和日期。
- 药品使用节点作为时间上下文，不作为疗效证明。
- 选中时间点后展示当日可见事实、用户原文和来源。
- 固定保留“相邻记录只作时间上下文，不表示关联或疗效”的说明。

### 9.4 产品与药膏使用档案

用户目标：辨认正在或曾经使用的药品，并保存个人使用记录。

产品首页：

- 产品角色定义为“药膏使用档案”，不是美妆货架。
- 真实包装图只作为识别锚点，占比克制。
- 列表展示通用名、浓度、剂型、状态、开始日期和个人记录状态。
- 不展示价格、销量、评分、购买按钮或推荐排名。
- 标题区可以使用 10%–14% 的透明容器、暖光与叶影背景，药品列表区不使用。

药品详情：

- 先展示包装与基础药品信息。
- 再展示用户开始日期、频率、停用状态和个人笔记。
- 可链接到历程中的时间节点，但不计算或宣称因果。
- 客观药品资料与个人记录必须视觉分区。
- 安全信息、来源和“非医疗建议”说明不得被折叠到难以发现的位置。

## 10. 跨页面影像剂量

| 页面类型 | 影像剂量 | 表达方式 |
|---|---:|---|
| 首页、引导页 | 25%–30% | 一主一辅编辑拼贴，允许完整品牌气氛 |
| 普通任务、药品页 | 10%–18% | 一张识别图或低强度背景痕迹 |
| 拍摄、证据、结果、历程 | 证据决定 | 真实照片优先，装饰不得进入证据区 |
| 设置、表单、错误 | 0% | 纯净 Paper 底，只依靠文字、间距和功能状态 |
| 空状态、加载 | 0%–16% | 加载优先骨架；空状态可按页面响度使用一种低强度痕迹 |

## 11. 共享组件

实施时优先建立以下语义组件，页面不得各自复制一套外观：

- App Shell：安全区、页面背景、底部导航。
- Top Bar：返回、关闭、标题、更多、添加。
- Primary / Secondary / Text / Icon Button。
- Section Header 与 Editorial Metadata。
- Region Chip 与 Status Chip。
- Evidence Photo：原始照片、日期、区域、来源标签。
- Observation Summary：结论、发现、下一步与边界说明。
- Timeline Strip：照片、日期、选中状态、使用节点。
- Medicine Card：包装图、通用名、浓度、剂型、状态和日期。
- Personal Record Block：用户原文与可见性说明。
- Quiet Notice：安全、来源、非因果与非诊断信息。
- Bottom Sheet / Modal：仅在需要保留页面上下文时使用。
- Empty / Loading / Error：统一系统状态。

新组件必须具有跨页面复用价值；仅改变排版密度时，应使用现有组件的插槽或变体，而不是创建同义组件。

## 12. 状态与恢复

### 12.1 拍摄状态

- 相机权限未开：说明原因，并提供开启权限或改用相册。
- 光线不足或图像模糊：指出具体问题，允许直接重拍。
- 上传失败：保留已拍照片和用户文字，提供重试与安全退出。

### 12.2 观察结果状态

- 分析中：骨架布局与最终内容几何一致，动效低刺激。
- 无法形成稳定观察：诚实说明原因，不生成虚假结论；建议重拍或仅保存原始记录。
- 保存失败：保留全部输入和照片，不让用户重新填写。

### 12.3 档案与产品状态

- 空档案：说明还没有记录及其价值，只提供一个合适动作。
- 数据缺失：显示“待补充”，不以空白或猜测值代替。
- 资料错误：说明来源或加载问题，提供重试和退出。

## 13. 无障碍与内容规则

- 正文、说明和按钮满足目标平台的对比度要求。
- 点击区域符合舒适触控尺寸。
- 选中、错误、成功、禁用除颜色外还需边框、图标、文字或位置变化。
- 皮肤状态不用羞辱、恐吓或“修复缺陷”语言。
- 观察文案描述可见事实和不确定性，不替代医生诊断。
- 药品信息不提供个体化处方建议。
- 用户照片、药品记录和个人原文应明确隐私与可见性。

## 14. 设计实现架构

实施层应分为四层：

1. **基础令牌**：颜色、字体、间距、圆角、细线、透明度与动效。
2. **共享组件**：导航、按钮、证据照片、观察摘要、时间线和药品卡片。
3. **页面模式**：品牌首屏、任务页、结果页、时间线页、档案列表与详情。
4. **业务页面**：观察、历程、产品和我的。

装饰痕迹作为独立的背景层或组件变体存在，不能写进证据照片、药品图片或数据组件内部。这样可以统一风格，并在无障碍、性能或特殊场景中安全关闭装饰。

## 15. 迁移顺序

1. 盘点现有页面、组件和设计令牌，识别可复用部分。
2. 建立全局令牌、字体角色、App Shell、导航和按钮。
3. 实现四组金标准页面，作为视觉回归基准。
4. 按页面模式迁移其余页面，而不是逐页自由设计。

## 16. 验收标准

全局验收：

- 去掉 Logo 后，各页面仍能被识别为同一产品。
- 页面温暖、低饱和、有呼吸感，但正文和操作清楚可读。
- 没有卡片墙、仪表盘墙、过度居中或多个竞争主按钮。
- 参考图片没有作为正式大图直接复用。

业务验收：

- 用户能从首页顺利完成拍摄、确认、保存和回看。
- 用户皮肤照片在所有页面保持真实、无修饰。
- 观察结果能在首屏找到结论、证据和下一步。
- 历程能按区域与日期回看，并明确非因果边界。
- 药品页能辨认真实药膏，保存个人使用信息，不像电商货架。

工程验收：

- 颜色、字体、间距、圆角和痕迹透明度使用共享令牌。
- 实现前必须同时核对 v1.1、v1.2 和本规范；三者的职责和优先级遵循第 3 节。
- 同语义控件使用同一组件及明确变体。
- 关键页面具备加载、空、错误和恢复状态。
- 关键手机视口无横向溢出，长文案与长药名有稳定处理。
- 核心流程具备自动化交互测试和视觉回归截图。

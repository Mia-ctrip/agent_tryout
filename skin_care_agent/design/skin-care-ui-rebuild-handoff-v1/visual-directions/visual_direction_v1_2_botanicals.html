Where the page breathes, a plant may quietly grow.

v1.1 定的是 秩序——象牙的底、苔藓的重点、克制的层级。这一份 v1.2 定的是 空气—— 在 hero、空状态、仪式时刻这些"允许氛围出场"的角落，放入五种"痕迹感"的植物语言： 散景、拓印、拖影、颗粒、剪影。它们从不参与信息，只参与感受。

01五种痕迹

Five Traces

每一种手法都取自"过程留下的痕迹"，不是"完成的物件"。所以画面永远软、永远像隔着一层——像相纸的散景、像宣纸的拓印、像雨水冲过玻璃的拖影。这五种手法可以单用，也可以叠加。

01

散景

Bokeh · 光斑

大光圈拍植物时留下的柔光斑。用径向渐变色斑 + 整体 blur 生成——是"看进去、化开来"的感觉。日常界面里最安全的一种氛围，因为它没有形状，只有光。

02

拓印

Ink Print · 敲拓叶脉

真实压制过的一整片叶——主脉、侧脉、细密网脉都留在纸上。SVG 手绘完整叶片 + 宣纸纤维底 + feDisplacementMap 让边缘微微失焦，模拟汁液渗透宣纸的痕迹。绿色和暖黄色因氧化并存，是"存在过、留下来"的证据。

拖影

04参数与 Token

For engineers

装饰层不是自由创作，而是有边界的参数。以下是可以直接落到 theme.ts 的一组 overlay tokens，与 v1.1 的 color/spacing/radii 平行。

Opacity 密度阶梯

overlay.whisper = 0.08 // 极轻，日常表面 overlay.soft = 0.16 // 空状态、次要氛围 overlay.medium = 0.28 // 印章叠印、剪影 overlay.strong = 0.45 // 只在仪式深底上 // 任何单一装饰层不得 > 0.55

Blur 模糊阶梯

blur.grain = 0px // 颗粒不模糊 blur.bokeh = 2px // 散景整体 blur.foliage-1 = 4px // 剪影 · 中焦 blur.foliage-2 = 9px // 剪影 · 大焦 blur.foliage-3 = 14px // 边角出血远景

Blend 模式

grain-on-light → multiply grain-on-dark → overlay silhouette → normal + opacity kinetic-streak → normal + opacity print-layer → normal (SVG displacement)

Motion（可选）

// 只在仪式屏允许缓慢漂移 foliage-drift : 24s ease-in-out infinite // 幅度极小，不超过 6px / 3deg translate: 0 → 4px 0 rotate: 0 → -1.5deg // prefers-reduced-motion → 全部关闭

# Skin Care Agent 主题色规范

> 当前主题：鼠尾草。本文是视觉实施说明；产品色彩事实以 `design/product/skin_care_app_mvp_spec.md` 第 11 节为准。

## 1. 主题方向

主题以低饱和鼠尾草绿、奶油底色和柔白表面构成安静、自然的记录空间。草木绿用于品牌识别，深绿承担关键操作；蜂蜜金只提供少量提醒和上下文，不作为第二主色。

不使用颜色表达皮肤状态的好坏、改善或恶化，也不把记录渲染成红绿输赢。品牌草木绿不用于小字号正文。

## 2. 基准色

| 色彩角色 | 色值 | 主要用途 |
|---|---|---|
| 品牌草木绿 | `#9BAD50` | 品牌识别、导航选中、非正文强调和选中标识 |
| 主操作深绿 | `#71813C` | 主要按钮、关键交互和焦点状态 |
| 奶油底色 | `#F8F0DD` | 页面大面积背景和柔和状态背景 |
| 蜂蜜金 | `#E8C76A` | 提醒、生活背景等上下文和少量高亮 |
| 深苔灰 | `#46502C` | 标题、正文和高对比图标 |
| 柔白 | `#FFFDF7` | 卡片、弹层和照片区域背景 |

## 3. 语义化使用

| 语义角色 | 对应基准色 | 使用规则 |
|---|---|---|
| `brand` / `selected` | 品牌草木绿 | 用于已选导航、选中状态和品牌元素；不代替正文层级。 |
| `actionPrimary` / `focus` | 主操作深绿 | 用于每个界面的主要行动和焦点；同一界面只保留一个主要行动。 |
| `background` / `surfaceMuted` | 奶油底色 | 用于页面底色、低压力的状态容器，不用作大段正文底色。 |
| `context` / `highlight` | 蜂蜜金 | 用于提醒、生活背景贴纸和极少量高亮；不用于错误、成功或疗效判断。 |
| `textPrimary` / `iconStrong` | 深苔灰 | 用于主要文字、图标和需要高对比度的信息。 |
| `surface` / `photoSurface` | 柔白 | 用于卡片、弹层和照片周围的中性空间。 |

## 4. 应用边界

- 新四栏壳层和后续 MVP 页面必须使用语义 token；legacy 页面可保留原配色，除非随功能改造而进入新流程。
- 颜色默认按 80% 透明度使用；为文字可读性、边框对比度或主要操作需要时，可按具体场景提高不透明度。
- 错误、禁用、加载等状态应以语义 token、文案、图标和状态形态共同表达，不能仅靠颜色区分。
- 原始照片及其周围空间保持中性，避免以主题色滤镜、覆盖层或装饰性调色影响照片本身。

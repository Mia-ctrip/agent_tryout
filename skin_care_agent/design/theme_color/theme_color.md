产品品牌主题色确定为“紫鸢尾花”色系，后续 UI/UX 视觉设计以 `design/UI/theme_color/image.png` 为定稿色板。

| 色彩角色 | 色值 | 主要用途 |
|---|---|---|
| 品牌主色／紫鸢尾 | `#8F85CE` | 品牌识别、导航选中、关键图标、大字号装饰 |
| 淡薰衣草 | `#F2EFF8` | 轻选中、辅助容器、低压力提示 |
| 清新薄荷 | `#C5DCCC` | 生活贴纸、插画、局部清新表达 |
| 杏金 | `#ECD083` | 趣味互动、贴纸、轻量视觉亮点 |
| 主文字／深暖灰 | `#5A5651` | 标题、正文、图标和功能信息 |
| 页面背景／暖白 | `#FFFDF8` | 页面底色及真实照片周围的中性空间 |

【背景】

使用提供的护肤品背景图片作为固定视觉素材。

不要使用渐变、矢量图形、代码绘制形状或装饰色块，
重新模拟这张背景图。

背景应该：

- 低对比度
- 柔和
- 哑光
- 始终处于内容之后
- 文字后方不要出现清晰锐利的瓶身边缘
- 避免强烈高光
- 避免玻璃反光感

如果文字可读性不足，
可以在背景图上增加一层 Ground 色的暖米色遮罩，
透明度约 20%～35%。

不要把背景做成高亮透明玻璃或香水广告风格。

【字体与文字层级】

字体层级需要同时参考：

2. App 现有首页

保持：

- 小号 editorial eyebrow 文案
- 大尺寸优雅主标题
- 克制的正文
- 清晰的产品信息层级

如果项目已经存在统一字体，

优先复用首页现有的字体和文字样式。

【产品卡片】

产品卡片的感觉应该是：

“温暖的纸面 / 磨砂护肤品材质”

而不是透明玻璃拟态。

目标：

- 使用 Surface 系颜色
- 对比度低
- 圆角约 16dp
- 阴影非常轻
- 只需要和背景产生轻微层次差异

避免：

- 强烈 glassmorphism
- 镜面高光
- 明显的白色描边
- 很重的 elevation 阴影
- 明显的 backdrop blur

保持产品缩略图、标题、副标题、记录信息和右侧箭头排版整齐、安静。

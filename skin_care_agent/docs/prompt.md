## 一、业务背景

系统默认设定几个可检测区域：

- 额头
- 左脸颊
- 右脸颊
- 鼻周
- 口周
- 下巴
- 如现有业务支持，可增加“全脸”

用户完成拍照后，需要在照片上选择本次希望重点检测的位置。系统也可能根据当天任务预先选中必检区域，用户可以额外选择自己关心的位置。

这不是图片编辑、美颜或修图功能。所有交互都要围绕“获得稳定照片—选择关注区域—进行 AI 分析—理解结果”展开。

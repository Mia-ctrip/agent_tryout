## 2. 已确认的主流程

**拍照/选择原图 → 确认区域及必要的区域事件选择 → 原始观察保存成功 → 产品使用步骤（AI 在后台处理）→ 本次观察详情/结果。**

1. 只有观察保存成功后才进入产品步骤，明确显示照片已保存。AI 按现有后端流程启动，不等待产品填写。
2. 产品步骤标题：“今天用了哪些产品？”说明只记录截至现在真实发生的使用，不要求填完全天。
3. AI 提前完成、失败或状态更新，都不得抢占页面、关闭新增表单、清空草稿或自动跳结果页。状态提示保持轻量，不播放强制等待动画。
4. 用户保存使用、选择“今天还没用”或“暂时跳过”后，进入刚才那条观察的详情。AI 还在处理就显示真实状态；失败则显示已有失败恢复，不伪造结果。
5. 返回/取消不撤销已保存照片，不重新发起观察创建或 AI 任务。用户离开后，已保存观察和使用都能恢复。
6. 仅在新观察保存后的主流程主动询问一次。历史回看、再次打开观察详情及恢复已保存记录时，不强制重复填写。

## 3. 产品选择与页面分工

### 默认选择界面

- 展示自己的常用、最近使用产品，优先复用已有真实频次/时间数据，不构造推荐分数。
- 支持多选，不默认勾选；产品图片、名称与选中状态清楚，小屏可操作。空柜也能搜索或添加。
- 提供“搜索或添加产品”入口。使用时间默认当前且允许修改；时间与备注按需展开，避免把默认界面变成长表单。
- 一次保存表示同一真实时间的一次使用，可包含多个产品。不同时间分别追加，不把拍照时间自动当作使用时间。

### 三条搜索路径

| 情况 | 用户动作 | 必须得到的结果 |
|---|---|---|
| 个人柜已有 | 选中 | 加入当前选择，不重复入柜 |
| 标准目录有且未入柜 | 加入并选中 | 完成入柜后选中；原先选择保留 |
| 搜索成功但无匹配 | 添加“搜索词” | 就地打开自建表单，名称预填且可改、图片可选 |

- 同时搜索个人产品柜与标准目录。目录项若已经入柜，按已有产品选中，不能重复创建。
- 搜索请求失败应显示重试，不能伪装成无匹配。保留现有搜索防抖与过期响应保护。
- 自建用当前流程内的弹层或展开表单，禁止要求用户跳到产品 Tab 后再回来。
- 新增成功收起子表单并选中新产品，保留原先选中的产品、时间和备注。
- 取消新增仅关闭子表单，回到原选择。系统返回键、关闭按钮、键盘与图片选择器返回都要正确处理，避免连续叠多层弹窗。
- 新增失败保留输入，允许重试或取消。不能因此丢失照片、已选产品或退出本次观察。

### 页面分工与返回

- 产品 Tab：产品柜管理、搜索新增、详情、官方资料与使用历史；不新增“记录使用”入口。
- 观察首页：保留独立“记录产品使用”快捷入口。
- 本次结果页及当天记录：提供“继续记录产品使用”，即使当次跳过或今天还没用，也能后来追加。不要只在 AI 成功后才允许访问使用入口。
- 从观察详情进入使用页，保存/取消后回到原观察；从观察首页独立进入，保存/取消后回到观察首页。
- 不再固定跳到历程，也不能返回拍照页要求重新拍摄。

## 4. 提交语义，必须区分

| 操作 | 是否产生个人产品 | 是否产生使用记录 |
|---|---|---|
| 标准加入或自建成功 | 是，标准项需去重 | 否，只选中 |
| 新增表单未提交就取消 | 否 | 否 |
| 选中产品并保存使用记录 | 复用已有个人产品 | 是 |
| 今天还没用 | 不因该操作新增 | 否，不表示全天未用 |
| 暂时跳过/取消使用步骤 | 不因该操作新增 | 否，不等同于未使用 |
| 明确选择“用过，但暂不注明产品”并提交 | 否，不创建伪产品 | 是，零产品关联，显示“未注明产品” |

- 有选中产品时，主操作文案“保存使用记录”。无选择时不能沿用当前“点击主按钮直接保存未注明产品”的行为；用次要入口显式选择“用过，但暂不注明产品”。
- 入柜与保存使用相互独立：已入柜后取消整个使用步骤，产品继续留在柜中，不回滚或删除；但不能产生使用次数或使用历史。
- 今天还没用、跳过、取消不生成假的 `ProductUse`，也不改写已有使用。无需为这两个退出动作新建“每日未使用”领域实体或额外统计系统。
- 产品使用保存失败要保留草稿并可重试；防止双击、超时重试、页面恢复造成重复产品、使用或观察。成功与否以服务端保存结果为准；利用现有幂等能力。
- 如果使用已保存但后续导航/页面刷新失败，不再次提交一条使用记录。
- 日内追加是真实新使用，不按“同一天同产品”粗暴去重，不覆盖原记录。历史回看提示不能变成默认勾选。
- 观察与使用仍为独立事实，流程来源仅用于衔接与返回；不得推导产品对区域的疗效，不将产品、使用备注或生活背景送入照片 AI，不改写现有历史快照。

## 6. 必须验证的行为

1. 新照片保存成功后出现产品步骤；已有观察仅创建一次。观察保存失败时不进入该步骤。
2. 分别模拟 AI 慢、即时完成、处理中变失败、部分区域失败；产品选择/新增均不被中断。退出产品步骤后回到同一观察及真实状态。
3. 多选已有产品；标准新产品加入并选中；已入柜标准项不重复创建；空柜可添加。
4. 无匹配自建预填名称，图片可选；成功收起且保留原草稿，取消不创建；搜索/新增失败能恢复。AI 完成不能清空正在输入的名称。
5. 只加入产品再取消使用：产品在柜中，使用次数和历史不增加。
6. 今天还没用、暂时跳过、系统返回/取消、空选择均不误生成使用；明确未注明产品才生成零关联使用。
7. 使用保存失败与超时重试不丢草稿、不重复保存。保存成功后导航失败再恢复不新增第二条。
8. 结果页、当天记录、观察首页入口的保存/取消均回到正确来源。历史详情不重复强制询问；同一天可记录多次不同真实时间的使用。
9. 已保存观察与使用在重新进入/重启后仍可读取；前后台、图片选择器、键盘及 Android 返回键不破坏当前流程。不要把内存中未提交的选择展示成已保存使用。

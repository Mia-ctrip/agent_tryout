# 背景
Skin Care Agent 是面向希望长期回看皮肤外观变化用户的个人记录工具，包含 React Native + Expo 移动端和 FastAPI 后端。
当前核心闭环是：用户拍摄一张照片或从相册选择一张原图，主动选择一个或多个固定面部区域，系统只整理所选区域的中性可见状态，并把有效时间点组织到区域事件中回看。每条新观察必须有照片，文字作为区域补充；AI 失败后保留原图，支持重试或补充文字。独立的无照片文字观察不进入 MVP，已有文字历史保留。实际产品使用与生活背景是独立事实，可以按时间并列展示，但不参与 AI、趋势、推荐、相关性、疗效或因果判断。
用户可点击“全脸”一次选中六区，AI 仍分别处理六个区域。全脸结果用完整原图汇集当次选区已有事实，历程提供全脸照片与分区事件两种回看；不新增全脸综合 AI 结论或全脸事件。界面“全脸”不等于旧数据类型 full_face，新记录仍只创建 region 目标；只选部分区域的照片也可在全脸历程回看，并明确当次观察范围。
底部导航固定为观察、历程、产品、我的。照片保存后、AI 结果展示前询问产品使用，AI 同时在后台处理；用户可从产品柜多选、就地搜索目录或自建产品，也可选择今天还没用或暂时跳过。新增产品只加入产品柜，提交使用后才形成使用事实。结果页、当天记录和观察首页支持继续记录使用；产品栏负责产品柜管理、搜索新增、产品历史及有来源的官方资料，不另设使用记录入口。完整范围、行为与验收只以 MVP 规格为准。


# 需求
本项目需要利用AI的图像分析能力处理以下三个场景：
1. 对当天单张照片的痘痘进行分析
2. 对指定两张照片呈现的痘痘趋势进行分析
3. 对多张痘痘照片组成的时间轴趋势进行分组
我希望你和我一起调整prompt的表述，使得识别出来的结果更符合我们产品的需求
